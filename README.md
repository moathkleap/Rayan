# ريان ونايا — Rayan & Naya 🎮

**مغامرة العوالم السبعة** — لعبة منصات ومغامرات ثنائية الأبعاد أصلية بالكامل، عربية الواجهة (مع دعم الإنجليزية)، مبنية بتقنيات الويب القياسية (HTML5 Canvas + WebAudio) دون أي مكتبات خارجية — تعمل على المتصفح، أندرويد، iOS، ويندوز، وماك.

## 🎮 العب الآن

**[https://moathkleap.github.io/Rayan/](https://moathkleap.github.io/Rayan/)** — مباشرة من متصفح الجوال أو الحاسوب، دون تحميل أو تثبيت.

## القصة

ريان فتى شجاع يعشق المغامرات، يعيش مع أخته الصغيرة نايا في قرية هادئة. أثناء استكشافهما أطلالًا قديمة يعثران على بوابة أسطورية مختومة، تخرج منها قوة مظلمة يقودها **ملك الظلال** الذي يختطف نايا ويقسم العالم إلى سبعة عوالم. يبدأ ريان رحلته لإنقاذ أخته — التي لا تنتظر الإنقاذ مكتوفة اليدين، بل تحاول الهرب وتحل الألغاز من داخل أسرها.

## التشغيل

اللعبة بلا خطوة بناء ولا اعتماديات:

```bash
# الطريقة الأسهل: افتح index.html مباشرة في المتصفح
# أو عبر خادم محلي (يُفعّل العمل دون اتصال عبر Service Worker):
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

**التحكم:** الأسهم/WASD للحركة • `K`/مسافة قفز • `J` هجوم • `L` اندفاع • `I` قذيفة طاقة • `O` إبطاء الزمن • `Esc` إيقاف مؤقت — مع دعم كامل لأزرار **اللمس** على الجوال و**يد التحكم** (Gamepad API)، وجميع الأزرار قابلة لإعادة التخصيص من الإعدادات.

## الشخصيات

صُممت الشخصيتان كرسم كرتوني متجهي إجرائي (procedural vector art) مستمد من الهوية البصرية الحقيقية:

- **ريان**: شعر بني داكن قصير مع غرّة، بشرة قمحية فاتحة، ابتسامة دافئة، تيشيرت أبيض بشعار لوح تزلج، شورت كحلي — مع 16 حالة حركة (وقوف، مشي، جري، قفز مزدوج، تسلق، اندفاع، هجوم، انتصار...).
- **نايا**: شعر بني داكن مجعد مع فيونكة، فستان كريمي منفوش بزخرفة زهرية، عقد وسوار خرز — شخصية ذكية وقوية تظهر في المشاهد بحالات متعددة (تفكير، محاولة هروب، تشجيع...).

لأن الرسم كود متجهي وليس صورًا نقطية، فهو حاد على شاشات Retina و4K ويقبل تبديل الملابس/الألوان فورًا.

## البنية البرمجية (Modular Architecture)

```
index.html            نقطة الدخول + طبقة أزرار اللمس
css/style.css         أنماط الصفحة وأزرار اللمس
manifest.webmanifest  PWA قابل للتثبيت
sw.js                 Service Worker (عمل دون اتصال)
js/
├── core/             أنظمة عامة مستقلة عن اللعبة
│   ├── utils.js      رياضيات، عشوائية مزروعة، ألوان
│   ├── i18n.js       الترجمة (عربي/إنجليزي)
│   ├── input.js      لوحة مفاتيح (قابلة للتخصيص) + لمس + يد تحكم
│   ├── audio.js      موسيقى إجرائية ديناميكية + مؤثرات مُخلّقة
│   ├── save.js       ملفات حفظ متعددة + تصدير/استيراد
│   └── engine.js     حلقة لعبة بخطوة ثابتة 60Hz + مدير مشاهد + Retina
└── game/
    ├── config.js     تعريف العوالم/الصعوبة/الملابس/القوى (data-driven)
    ├── physics.js    تصادم بلاطات AABB، منصات أحادية، جليد/رمال
    ├── characters.js رسم ريان ونايا وملك الظلال
    ├── particles.js  جزيئات + طقس لكل عالم
    ├── background.js Parallax متعدد الطبقات
    ├── levelgen.js   مولّد الـ56 مرحلة + ساحات الزعماء + الرسم
    ├── entities.js   كيانات تفاعلية (30+ نوعًا) + مقذوفات
    ├── enemies.js    28 عدوًا بسلوكيات AI
    ├── bosses.js     7 زعماء بثلاثة أطوار
    ├── player.js     تحكم ريان وكل القدرات
    ├── achievements.js 110+ إنجاز
    ├── hud.js        واجهة اللعب + مكوّنات UI
    ├── cinematics.js المقدمة/السجون/الذكريات/النهاية
    ├── levelscene.js مشهد اللعب (كاميرا، موسيقى ديناميكية، نتائج)
    └── scenes.js     القائمة/الملفات/الخريطة/المتجر/الإعدادات/الإنجازات
```

**التوسعة المستقبلية دون إعادة بناء:**
- عالم جديد = إضافة كائن في `C.WORLDS` + أعداء في `ENEMY_DEFS` + زعيم في `BOSS_DEFS` + مشهد سجن في `PRISON_SCENES`.
- عدو جديد = سطر تعريف في `ENEMY_DEFS` (أرشيتايب حركة جاهز) + فرع رسم.
- زي/قوة/لغز جديد = إدخال بيانات في `config.js`.
- شخصيات قابلة للعب مستقبلًا: `Player` يستقبل دالة رسم و`OUTFITS` منفصلة.
- الحفظ السحابي: استبدل `Save.exportCode/importCode` بمزامنة خادم.

## النشر على المنصات

| المنصة | الطريقة |
|---|---|
| **Web** | ارفع الملفات كما هي على أي استضافة ثابتة (GitHub Pages / Netlify / Vercel). PWA قابلة للتثبيت. |
| **Android** | [Capacitor](https://capacitorjs.com): `npm i @capacitor/core @capacitor/cli && npx cap init && npx cap add android && npx cap sync && npx cap open android` — أو TWA عبر [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap). |
| **iOS** | Capacitor: `npx cap add ios && npx cap sync && npx cap open ios` (يتطلب Xcode). |
| **Windows / macOS / Linux** | [Tauri](https://tauri.app) (الأخف): `npm i -D @tauri-apps/cli && npx tauri init` مع توجيه `distDir` لجذر المشروع — أو Electron. |

اللعبة مصممة على دقة افتراضية 960×540 تتمدد لأي شاشة (حتى 4K) مع دعم devicePixelRatio، وخطوة فيزياء ثابتة 60Hz مستقلة عن معدل الإطارات، وإعداد جودة مؤثرات (منخفض/متوسط/عالٍ) للأجهزة المتواضعة.

## English Summary

**Rayan & Naya** is a fully original 2D platform-adventure built with vanilla HTML5 Canvas + WebAudio (zero dependencies). 7 themed worlds × 8 levels, 7 three-phase bosses, 28 enemy types with distinct AI (patrol/chase/flee/ambush/pack/adaptive), earnable abilities (double jump, dash, wall jump, glide, slam, energy shot, time-slow), puzzles (keys, levers, timed buttons, push-boxes, torches, mirrors), secrets & 12 collectible memories, 110+ achievements, shop with outfits & upgrades, dynamic procedural music, cinematic cutscenes, 4 difficulty modes, accessibility options, multi-profile save with export/import, touch + keyboard + gamepad, Arabic/English UI. Open `index.html` to play; package with Capacitor (Android/iOS) or Tauri/Electron (desktop).
